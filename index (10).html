Donut SMP tools, inside Discord.

Donut Utils is a Discord bot that looks up player stats and item worth, so your server doesn't have to leave chat to check.

Add to Discord Join the support server

What it does

Player stats

Look up a player's stats by username.

Item worth

Check what an item is worth.

Slash commands

Discord shows you what's available as you type.

About the developer

Donut Utils is built and run by iitzrob, an experienced developer who has built over 7 Discord bots. Three of them run in large servers, including one with about 2,000 members and another with about 2,100. The rest are anonymous projects.

Questions, bugs or ideas? Come say hi in the support server.

Getting started

Add the bot, keep the permissions it asks for, then type / in any channel it can see to browse its commands.
